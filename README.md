# yourview-social# YourView Social

YourView Social is a modern social networking platform built with Next.js, TypeScript and Supabase.

## Features

- User registration and login
- User profiles
- Social feed
- Create posts
- Like and comment
- Follow users
- Notifications
- Messaging
- User settings
- Responsive design
- Supabase authentication
- Supabase database
- Supabase storage

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Project

YourView Social is part of the YourView ecosystem.
